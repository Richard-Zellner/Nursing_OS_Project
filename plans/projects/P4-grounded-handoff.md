- P3 finished, or at least its local HAPI server (P3-M4-1) working.
- Owner: read the prior art first: Hartman et al., JAMA Network Open 2024; and
  "Verifying Facts in Patient Care Documents Generated by LLMs Using EHRs"
  (NEJM AI; confirm the citation).
- M1 task: confirm the US Core version for the README statement (the HTI-1
  baseline; check the Federal Register text) and the current status of the
  HL7 AI Transparency IG.

| Public HAPI outages | Local server only; use hapi.fhir.org for smoke tests at most |
